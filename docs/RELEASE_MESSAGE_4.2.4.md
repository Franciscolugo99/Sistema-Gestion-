# FLUS 4.2.4

FLUS 4.2.4 es un hotfix para instalaciones 4.2.x.

## Incluye

- Correccion de movimientos de caja en instalaciones con PHP 8.0.
- Respuestas JSON consistentes para el modal de movimientos de Caja.
- Dashboard Top productos por unidades, ventas o ganancia.
- Limite configurable de Top productos sin recargar la pagina completa.
- Sin migraciones nuevas sobre 4.2.3.
- Preservacion de configuracion, licencia, archivos y base existente.

## Archivos

- `FLUS_Server_Setup_4.2.4.exe`
- `FLUS_Terminal_Setup_4.2.4.exe`

Ruta local:

`C:\Users\Martin\Documents\FLUS_installer_V4.2.4\installer\output`

## Recomendacion de instalacion

1. Hacer backup de la maquina actual.
2. Ejecutar el instalador servidor como administrador.
3. Confirmar que FLUS muestre `v4.2.4`.
4. Probar login, licencia, caja, movimientos manuales y una venta.
5. Probar Dashboard con Top productos por unidades, ventas y ganancia.
