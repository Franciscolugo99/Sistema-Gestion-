# FLUS 4.2.0

FLUS 4.2.0 incorpora control de disponibilidad de promociones para Caja.

Desde Promociones se puede apagar la aplicacion de descuentos o programar una
pausa diaria. Durante esa franja, Caja recalcula el carrito sin promociones y el
backend tambien bloquea su aplicacion, manteniendo el comportamiento consistente
entre pantalla, API y motor comercial.

Artefactos:

- `FLUS_Server_Setup_4.2.0.exe`
- `FLUS_Terminal_Setup_4.2.0.exe`
