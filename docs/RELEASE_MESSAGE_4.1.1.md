# FLUS 4.1.1

FLUS 4.1.1 es un parche operativo sobre la version 4.1.0.

Incluye una Caja mas compacta y coherente, mejor respuesta en pantallas angostas,
pagos divididos editables, validacion correcta de importes parciales de Mercado
Pago, restauracion segura de costos en compras y compatibilidad de snapshots de
stock para instalaciones legacy. Tambien centraliza la configuracion de tickets,
mejora la impresion termica e incorpora logo y datos operativos opcionales.

Artefactos:

- `FLUS_Server_Setup_4.1.1.exe`
- `FLUS_Terminal_Setup_4.1.1.exe`

Los instaladores deben recompilarse desde el build `2026-06-11` antes de su
distribucion.
