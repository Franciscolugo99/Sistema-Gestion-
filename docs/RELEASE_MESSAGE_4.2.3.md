# FLUS 4.2.3

FLUS 4.2.3 es un patch de cierre QA para instalaciones 4.2.x.

## Incluye

- Upgrade compatible desde 4.2.0, 4.2.1 y 4.2.2.
- Correccion de la busqueda en Consulta de stock.
- Confirmacion visible al registrar ventas sin vuelto desde Caja.
- Confirmacion visible para Mercado Pago manual despues de cancelar QR.
- Sin migraciones nuevas sobre 4.2.2.
- Preservacion de configuracion, licencia, archivos y base existente.

## Archivos

- `FLUS_Server_Setup_4.2.3.exe`
- `FLUS_Terminal_Setup_4.2.3.exe`

Ruta local:

`C:\Users\Martin\Documents\FLUS_installer_V4.2.3\installer\output`

## Recomendacion de instalacion

1. Hacer backup de la maquina actual.
2. Ejecutar el instalador servidor como administrador.
3. Confirmar que FLUS muestre `v4.2.3`.
4. Probar login, licencia, caja, una venta, Mercado Pago manual y consulta de
   stock.
