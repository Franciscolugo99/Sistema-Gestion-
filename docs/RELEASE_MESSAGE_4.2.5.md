# FLUS 4.2.5

FLUS 4.2.5 incorpora actualizacion protegida y sincronizacion Cloud automatica.

## Incluye

- Backup verificado antes de reemplazar archivos en upgrades.
- Preservacion de DB, licencia, storage, ARCA y Mercado Pago.
- Configurador Cloud con diagnostico y reparacion guiada.
- Envio automatico de pendientes con idempotencia, locks y reintentos.
- Estado operativo visible desde Tecnico.
- Instaladores reproducibles y hashes SHA256.

## Instalacion recomendada

Realizar primero un piloto descartable. Luego actualizar una sola PC productiva,
validar Caja y Cloud, y recien despues continuar con la segunda.
