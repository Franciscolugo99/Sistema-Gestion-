# FLUS 4.2.1

FLUS 4.2.1 incorpora la validacion cloud de licencias para que el estado de una
instalacion pueda controlarse desde FLUS Admin/Wiros.

## Incluye

- Consulta cloud firmada y cache offline.
- Suspension, vencimiento, revocacion y reactivacion remota de licencias.
- Instalador servidor preparado para configurar la API cloud.
- Compatibilidad con instalaciones existentes de 4.2.0.
