# FLUS 4.2.2

FLUS 4.2.2 consolida seguridad, licencias cloud, compatibilidad del instalador
y correcciones operativas para instalaciones existentes.

## Incluye

- Upgrade compatible desde 4.2.0 y 4.2.1.
- Reparacion automatica de OpenSSL en el stack portable.
- Preservacion de configuracion, licencia, archivos y base existente.
- Menor exposicion de errores internos.
- Mejoras de sesiones, terminales, backups y pantalla de licencia.
- Busqueda de stock priorizando productos activos.
- Proteccion contra doble envio en movimientos de caja y ajustes de stock.
- Cierre de caja coordinado con ventas en curso para evitar estados inconsistentes.
