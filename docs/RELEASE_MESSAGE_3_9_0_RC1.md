# FLUS 3.9.0-rc1

Fecha: 2026-04-20

FLUS 3.9.0-rc1 queda como candidato de release para validar en operacion real antes de cortar la version final 3.9.0.

## Incluye

- Base tecnica con smoke en verde.
- Migraciones y baseline validados en upgrade e instalacion limpia.
- Tesoreria v1 incorporada al alcance operativo.
- Facturacion comun, documental, visor, PDF, recovery y notas de credito alineadas a nivel tecnico.
- Homologacion fiscal local con preflight apto y ARCA respondiendo.
- Compras, Clientes y Proveedores con mejoras recientes de UI, notificaciones y datos demo para revision operativa.

## Pendiente antes de 3.9.0 final

- QA funcional corta en Caja, Compras, Tesoreria y Facturacion.
- Validacion fiscal real de produccion con datos del negocio.
- Cerrar numeracion, emision de QA y recorrido operativo completo en el entorno objetivo.

## Criterio de uso

Este build puede usarse para validacion controlada y QA operativo. No debe considerarse aprobacion de emision fiscal real hasta completar la configuracion fiscal y la prueba end-to-end en el entorno correspondiente.
